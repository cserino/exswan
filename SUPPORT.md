# Support

Use GitHub Discussions for usage questions and design discussions, if Discussions are enabled. Use GitHub Issues for reproducible defects and focused feature requests.

Before you open an issue:

1. Check the package README and API documentation.
2. Search existing issues and discussions.
3. Reproduce the problem with the latest package release.

Include the package version, Elixir and OTP versions, relevant configuration, expected result, and actual result. Provide a small reproduction when possible. Remove credentials and personal data.

For suspected vulnerabilities, follow [SECURITY.md](SECURITY.md) and report them privately.

This project is maintained on a best-effort basis. There is no guaranteed response time for general support.
