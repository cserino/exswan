# Security Policy

ExSwan processes authentication data. Please report suspected vulnerabilities privately.

## Reporting a vulnerability

Use the **Report a vulnerability** button on the repository's Security tab to open a private GitHub security advisory. Do not open a public issue for a suspected vulnerability.

If private vulnerability reporting is not enabled, contact the maintainer through the email address on the maintainer's verified GitHub profile. Include:

- the affected package and version;
- the impact you expect;
- steps or sample code that reproduce the problem; and
- any known workaround.

Do not include real credentials, personal data, or production secrets.

The maintainer will acknowledge a report within seven days and will provide an initial assessment within fourteen days. Fix and disclosure dates depend on severity and complexity. The reporter will receive credit unless they ask to remain anonymous.

## Supported versions

Before version 1.0, only the latest release of each package receives security fixes. Users should update to the latest release before reporting a problem that might already be fixed.

## Scope

Security reports can cover the `exswan` and `exswan_plug` packages, the release process, or the example application's use of those packages. The example application is not a supported production application.
